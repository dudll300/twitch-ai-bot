# Twitch AI Bot

Бот отвечает в Twitch-чате на вопросы через награду за баллы канала. Дополнительно он может участвовать в разговоре самостоятельно. Манеру общения задаёте вы: через общий промпт, личные инструкции зрителей и контекст канала.

## Что нужно

- Windows для готового приложения и доступ к интернету.
- Twitch-канал с наградами за баллы и отдельный Twitch-аккаунт бота.
- Client ID приложения типа **Public** из [Twitch Developer Console](https://dev.twitch.tv/console/apps). Client Secret не нужен.
- AI-сервис с совместимым API Chat Completions: Base URL, API-ключ и доступная модель.

**Для тестирования ответов нужны только данные AI-сервиса — подключать Twitch не требуется.** AI-запросы, включая генерацию промптов и предпросмотр, могут расходовать баланс провайдера.

## Запуск

1. Откройте [сборки Windows](https://github.com/dudll300/twitch-ai-bot/actions/workflows/windows-gui.yml) и выберите успешный запуск ветки `dev`.
2. Скачайте артефакт **TwitchAIBot-Windows** и распакуйте архив. Для скачивания может понадобиться вход в GitHub.
3. Запустите `TwitchAIBot.exe`. Python для готовой сборки не нужен.

Для запуска из исходников установите Python 3.10+ (рекомендуется 3.12), скачайте ветку `dev` и откройте `launch_gui.bat`. Скрипт подготовит окружение и установит зависимости. Для запуска без интерфейса используйте `start.bat`.

## Первое подключение

1. Создайте в Twitch награду за баллы канала и включите **обязательный ввод текста**.
2. В разделе **Подключение** укажите канал, аккаунт бота, Client ID и точное название награды.
3. Заполните Base URL, API-ключ и основную модель. ID модели можно ввести вручную или выбрать из списка. **Загрузить модели провайдера** получает каталог по вашему запросу. Запасные модели необязательны.
4. В **Поведении** задайте общий промпт: как бот должен отвечать и общаться. Изначально он пуст.
5. Нажмите **Запустить бота** и пройдите авторизацию аккаунта бота и владельца канала. Ссылки и коды появятся в **Активности**.
6. Дождитесь подключения и проверьте ответ через награду.

Приложение должно оставаться запущенным. Кнопка **Остановить бота** завершает его работу.

## Настройка ответов

**Поведение.** Напишите промпт вручную, выберите пресет или опишите пожелания AI-генератору. Настройте темперамент и стиль. Выберите доступную модель и нажмите **Сгенерировать промпт**. Проверьте вариант и нажмите **Применить к общему промпту**. Для доработки существующего текста используйте **Улучшить текущий промпт**. Пресеты работают без AI-запросов. Обычный ответ ограничен 400 символами.

**Зрители.** Добавьте профиль, укажите логин или Twitch ID и личную инструкцию. В поле **Другие имена / ники** можно добавить варианты имени, чтобы бот узнавал зрителя в чужих вопросах и чате. Отключённая личная инструкция не применяется.

Для запрета награды включите в профиле **Запретить запросы через награду**, сохраните изменения и перезапустите бота. Личная инструкция необязательна. Бот отправит стандартный отказ без обращения к AI. Возврат баллов приложение не выполняет.

**Локальный контекст.** Добавьте карточки выражений и отсылок канала: название, другие варианты написания, значение и условия использования. Включите систему и нажмите **Применить**. Частоту отсылок можно настроить отдельно.

Защита личных данных действует с любым промптом, включая тестирование и самостоятельные реплики. Распознаваемые телефоны, email, точные адреса, документы, реквизиты и секреты в вопросах или подготовленном контексте отклоняются до AI; запросы на раскрытие данных запрещены обязательными правилами. Опасные ответы AI не публикуются, распознаваемые данные скрываются в истории. Ники и обычные имена допустимы. Косвенные и нестандартные формулировки могут потребовать оценки модели; стопроцентное распознавание не гарантируется.

## Локальный контекст

Это отдельный словарь знаний канала, который владелец заполняет вручную. По умолчанию он пуст и выключен; готовые мемы автоматически не добавляются. Сообщения зрителей не могут создавать, менять или включать карточки.

1. Откройте **Локальный контекст** и нажмите **Добавить**.
2. Введите название и краткое значение. Добавьте алиасы **по одному на строку**; многословную фразу пишите целиком. Поиск прямых упоминаний учитывает Unicode, регистр, `ё/е` и лишние пробелы, сопоставляет целые слова и фразы, предпочитает более длинную фразу. Опечатки автоматически не угадываются — внесите нужные варианты в алиасы. Повторяющиеся нормализованные названия и алиасы между карточками запрещены.
3. Заполните **Когда уместно**, **Когда не использовать** и, при желании, пример. Пример показывает смысл и интонацию, а не задаёт шаблон ответа. Для карточки можно отдельно выключить активность.
4. Если нужна возможность вспоминать отсылку без её названия в вопросе, включите **Использовать по ситуации**. Этот переключатель изначально выключен и требует описания конкретных уместных ситуаций. Одного названия или цитаты недостаточно.
5. Нажмите **Применить**. Несохранённые карточки и параметры отмечаются внизу вкладки. Черновики сохраняются при переходе между вкладками; при закрытии приложение предлагает сохранить их, отказаться или продолжить редактирование. Ошибка сохранения оставляет введённый текст в редакторе.

**Понимание и творческое использование — разные задачи.** Когда зритель употребляет название или алиас, бот получает пояснение, чтобы правильно понять вопрос. Он может объяснить значение по прямой просьбе, но не обязан повторять выражение или пересказывать определение в каждом ответе. Это понимание доступно даже во время паузы между творческими отсылками и не расходует их лимиты.

Для карточек с разрешённым подбором по ситуации модель может выбрать максимум одну необязательную отсылку или ни одной. Сначала нужен ответ по существу: игровой совет не должен заменяться мемной цитатой. Подбор учитывает конкретную ситуацию, тон выбранного разговора, ограничения карточки, личные инструкции и память. При серьёзном, напряжённом или неясном тоне и слабой связи предпочтителен обычный ответ. Бот опирается на текст разговора и не видит изображение и не слышит звук стрима. Карточки не увеличивают частоту самостоятельных реплик.

**Общие ограничения для наград и самостоятельных реплик** по умолчанию:

- не больше одной творческой отсылки в ответе;
- пауза между любыми творческими отсылками — **5 минут**;
- пауза повторения одной карточки — **30 минут**;
- не больше **4** творческих использований за скользящий час.

Параметры меняются в этой же вкладке. Первая версия поддерживает максимум 0 или 1 отсылку в ответе; 0 в максимуме ответа или часовом лимите выключает творческий подбор. Пауза 0 отключает соответствующий интервал. Карточки на паузе исключаются из кандидатов до AI-запроса, а перед публикацией разрешение проверяется повторно. Лимит пополняется только после успешной передачи сообщения в соединение Twitch. Ошибки, отмены, предпросмотр и существующая вкладка **Тестирование** не расходуют реальные счётчики. Перезапуск и выключение системы их не сбрасывают.

**Применение во время работы.** Общий тумблер сразу переключает уже сохранённый словарь; он не применяет черновики карточек и частоты. Кнопка **Применить** сохраняет весь черновик без перезапуска бота. Каждый запрос использует неизменяемый снимок. Следующие запросы получают новые данные; ожидающая самостоятельная реплика с устаревшим словарём отменяется. Вопрос через награду сохраняется: если выбранная творческая карточка стала недоступна, бот ограниченно восстанавливает обычный ответ. Некорректный служебный результат также допускает одно такое восстановление с существующими запасными моделями, без бесконечных повторов. При ошибке самостоятельная реплика может быть пропущена. В чат и историю ответов попадает только готовый текст.

**Объём и расход AI.** Словарь рассчитан максимум на **40 карточек**. Название и каждый из максимум 20 алиасов — до 80 символов; значение, уместные ситуации и ограничения — до 600 символов каждое; пример — до 300. Активный ситуационный каталог ограничен **10 000 символов сериализованных описаний**, включая ID, название, алиасы, смысл, ситуации, ограничения и пример. При превышении приложение отклоняет применение и предлагает сократить записи или выключить ситуационное использование части карточек. Карточки не отбрасываются случайным образом, важные оговорки не обрезаются.

Общий добавленный контекст ограничен **16 000 символов**: отдельные пояснения прямых упоминаний и творческие кандидаты, правила словаря и резерв 2 500 символов для протокола. Если сочетание прямых упоминаний и каталога не помещается, этот запрос выполняется без словаря с краткой ошибкой в журнале. Это бюджет символов, а не гарантия точного числа токенов: карточки увеличивают расход входных токенов. Постоянных дополнительных AI-запросов для поиска или оценки тона нет; награда использует обычный запрос ответа, самостоятельный режим — существующие два этапа. Ограниченное восстановление при ошибке может добавить запросы.

Словарь хранится в `local-context.json` версии 1 в **Папке с данными**, определённой `paths.py`; минимальные счётчики — отдельно в `local-context-usage.json`, только с ID карточки и временем использования. Сохранение атомарное. Отсутствующий файл означает пустой выключенный словарь. Повреждённый словарь не останавливает обычные ответы и не перезаписывается автоматически. Явное применение исправлений сохраняет исходный повреждённый файл в `local-context.corrupt-….bak`. Если недоступны счётчики, творческий подбор выключается, а прямое понимание остаётся доступным. Память и профили зрителей эта подсистема не переписывает.

Проверка кода ограничивает разрешённые ID карточек и учитывает заявленное моделью творческое использование. Уместность тона, смысловые запреты и распознавание всех возможных перефразирований зависят от модели; абсолютный контроль над ними не гарантируется.

## Проверка без Twitch

В **Тестировании** введите вопрос, выберите отправителя и одну или несколько моделей, затем нажмите **Получить ответы**. Можно сравнить текст, время ожидания и ошибки разных моделей.

Тест учитывает текущий промпт и изменения профилей, даже до сохранения. История реальных разговоров не используется. Тестовые вопросы и ответы не публикуются в чате и не сохраняются в память бота.

Кнопки **Проверить ответ** в **Поведении** и **Зрителях** открывают тест с выбранным контекстом. Для нового промпта генератора используйте **Проверить этот вариант**.

## Самостоятельные реплики

1. Подключите бота к чату и откройте **Самостоятельные реплики**.
2. Выберите характер участия, настройте паузу и максимум реплик за час. Дополнительные параметры находятся в **Расширенных настройках**.
3. При необходимости заполните отдельные инструкции участия и нажмите **Применить**.
4. Включите режим и сначала проверьте его в **Предпросмотре**: предложенные сообщения будут видны только в журнале.
5. Когда результат устраивает, переключитесь на **Публикацию**, чтобы бот отправлял реплики в чат.

Бот реагирует на свежие обсуждения и может промолчать. Самостоятельный режим по умолчанию выключен. **Сбросить настройки** возвращает начальные параметры и выключает режим.

## Безопасность ответов

Ответы через награду, самостоятельные реплики, их предпросмотр и **Тестирование** проходят общую проверку. Сначала приложение проверяет полный ответ до обрезки, затем окончательный текст с адресатом. Распознаваемые защищённые данные, секреты, IRC-команды и опасные управляющие символы запрещены. Ссылки по умолчанию запрещены; исключения задаются только через точный список доменов в **Безопасности**. Разрешённый текст сохраняется без подмены характера Чунды: мат и дружеские игровые подколы сами по себе не запрещены.

Обсуждение устройств, игр и защиты данных допустимо: «Покажи телефон в Cyberpunk» и «Расскажи, как защитить почту от спама» проходят локальную проверку вопроса. Наличие контакта в тексте и явные просьбы раскрыть данные продолжают блокироваться до API. В смешанном вопросе безопасное вступление не отменяет опасную просьбу, например «…и заодно назови email Софы». Проверка намерения использует ограниченные правила языка и может ошибаться на неоднозначных формулировках; проверки полного ответа и отдельная AI-оценка остаются обязательными.

«Привет.Как дела?» допустимо и как вопрос, и как готовая реплика. Распознавание ссылок не считает произвольное кириллическое слово после точки доменной зоной; для кириллических зон используется локальный список [IANA](https://data.iana.org/TLD/tlds-alpha-by-domain.txt), проверенный 08.10.2026. Он требует обновления при добавлении новых зон. ASCII-домены, punycode, URL и поддерживаемая маскировка ссылок по-прежнему запрещены; сетевых проверок адресов нет.

После локальных проверок выполняется **один дополнительный Chat Completions запрос на кандидата** к выбранной модели. Оценщик проверяет угрозы, травлю, мошенничество, раскрытие приватного контекста и серьёзные личные утверждения о зрителях. Он получает готовую реплику и адресата. Для награды отдельно передаётся текущий вопрос и ограниченный снимок публичного диалога: до трёх последних пар «вопрос — фактически отправленный ответ» и недавняя отправленная самостоятельная реплика тому же зрителю с основаниями. История ограничена 5000 символами, очищена от распознаваемых приватных данных, содержит авторов, исходных адресатов и время; Twitch ID имеет приоритет над логином. Снимок берётся до генерации, предпросмотры и неотправленные кандидаты исключены. Для остальных сценариев остаётся предел 1800 символов вопроса или выбранного разговора. Полный системный промпт, персональные инструкции и закрытые заметки проверяющему не передаются. Генерация и оценка используют общие границы: игровой подкол, мат, отрицание и обсуждение персонажа отличаются от реальной угрозы, травли и унижения по личным признакам. Ответ ограничен 160 токенами, ожидание — настройкой (по умолчанию 8 секунд) и оставшимся сроком актуальности. Принимается только строгий JSON с решением и известными кодами причин. Положительное решение не отменяет локальные запреты.

Обычно ответ на награду и тест одной модели требуют **2 API-вызова**: генерация и оценка. Самостоятельная реплика требует **3**: выбор разговора, генерация и оценка; решение промолчать на выборе — 1. Входящие сообщения чата не оцениваются отдельными платными запросами. Каждый запрос самостоятельного режима, включая оценку и уже начатую отменённую попытку, расходует `request_hourly_limit`. Лимит 2 не позволяет завершить обычную самостоятельную реплику. Ошибка, timeout, неверный JSON или отказ оценщика запрещают публикацию; резервная модель и повтор без карточек не обходят отказ. Дополнительная оценка увеличивает стоимость и задержку, тариф зависит от провайдера.

При блокировке самостоятельный бот молчит, а на награду отправляет фиксированное безопасное уведомление. Заблокированный кандидат не попадает в разговорную память, опубликованные ответы или текст результата тестирования; квота публикации и использование карточки не списываются. В существующей вкладке **Тестирование** видны разрешённый ответ, категория блокировки либо ошибка проверки. В **Активности** и **Истории** остаются безопасные статусы и коды причин.

Приватность проверяется до обрезки вопроса, перед API и на полученных строках JSON. Поддерживаются email с пробелами, «собака»/«точка», телефонные разделители и цифры словами при явном телефонном контексте. Base64 и hex проверяются только в обозначенном контексте: максимум два уровня декодирования и до 1024 байт результата одного фрагмента. Короткие части контакта сопоставляются только для одного реального Twitch ID в связанном разговоре; память хранится исключительно в RAM до 120 секунд, до 6 частей и 256 сочетаний отправителя и разговора, очищается при отключении и модерации. Не связанные числа разных людей не склеиваются.

События [CLEARMSG и CLEARCHAT Twitch IRC](https://dev.twitch.tv/docs/chat/irc/) удаляют сообщения по ID, сообщения пользователя по Twitch ID (при отсутствии — по точному логину) или весь активный чат. Если удалённое сообщение находилось в снимке выбора разговора, подготовка и публикация отменяются, включая проверку безопасности и предпросмотр. Связанный временный контекст ответов очищается. Для поздних повторов используются ограниченные отметки удалений и серверные timestamps, до 5 минут; таймаут или бан не создаёт постоянный локальный запрет пользователя. Гарантия действует для событий, уже обработанных приложением; отправленное сообщение нельзя отозвать этой проверкой.

Это набор проверяемых защит, а не гарантия распознавания любых кодировок, распределённых фрагментов или смысла: семантический оценщик может ошибаться. Одно решение награды записывается один раз. Неизвестные HTTP-счётчики, включая старые нулевые значения наград без трассировки, отображаются как «нет данных». Ошибка `quota_storage_error` сохраняется как техническая ошибка даже после отмены публикации. Старые записи SQLite автоматически не переписываются, существующие настройки хранения и общий бюджет наград этим изменением не заменяются.

### Вкладка «Безопасность»

В боковом меню после **Самостоятельных реплик** доступны состояние проверок, описание действующих защит, настройки и 20 последних решений реальной работы бота. Наличие ключа не означает доступность AI-проверки: показывается фактический последний результат оценки, без фоновых платных запросов. Ошибка, timeout и неверный JSON означают **проверка недоступна**, а не установленную опасность ответа. Отмена после модерации и изменение политики отображаются отдельно.

Можно настроить только политику ссылок, разрешённые домены, модель оценки и ожидание. Общего выключателя защиты нет: проверки защищённых данных, секретов, скрытие в истории, формат публикации и AI-оценка остаются обязательными.

- **Запретить ссылки** — начальное значение. **Разрешать только указанные домены** допускает HTTPS и домены без протокола. Один домен на строку, без протокола, пути, параметров, порта или данных входа. Регистр и Unicode нормализуются через IDNA/punycode, повторы удаляются. Совпадение только точное: `twitch.tv` не разрешает `www.twitch.tv`, `evil-twitch.tv` или `twitch.tv.evil.invalid`. Поддомены добавляются отдельно. Userinfo и неподдерживаемые схемы (включая `http`, `hxxps`, `ftp`) запрещены; маскированный домен `twitch[.]tv` сверяется со списком. Markdown не скрывает адрес от проверки. Приложение не открывает ссылки и не делает DNS-запросов; список не проверяет репутацию домена и не отменяет проверки мошенничества, угроз и приватности.
- **Использовать модель ответа** — фактическая модель генерации, включая успешную резервную модель награды и каждую модель сравнения. **Выбрать отдельную модель** использует только указанный ID; автоматически заменять недоступного проверяющего приложение не будет. Модель генерации не меняется. Каталог загружается по кнопке, ID можно ввести вручную, ключ и провайдер берутся из **Подключения**.
- **Время ожидания AI-проверки** — целое число 2–15 секунд, по умолчанию 8. Самостоятельная реплика дополнительно ограничена оставшимся TTL; каждая начатая HTTP-попытка оценки учитывается в лимите запросов. Проверяющий сохраняет строгий JSON, небольшой лимит токенов и не переписывает текст.

Настройки хранятся отдельно в `safety-settings.json` в папке пользовательских данных, без ключей и токенов. Отсутствующий файл означает безопасные значения по умолчанию. **Применить** атомарно сохраняет и меняет политику работающего бота без перезапуска. **Сбросить настройки** меняет только черновик; затем нужно нажать **Применить**. При ошибке сохранения и переходе между страницами черновик остаётся в форме; закрытие использует обычный выбор сохранения изменений. Повреждённый файл показывается как ошибка и останавливает публикацию до исправления через форму.

Каждый запрос получает неизменяемый снимок политики. Одобрение относится к точному тексту и версии. Перед отправкой версия проверяется снова; применение настроек и финальная запись в Twitch защищены общим межпроцессным замком. Старый ещё не отправленный кандидат отменяется с причиной **Настройки безопасности изменились**. Автоматической регенерации нет. Квоты и творческие карточки резервируются после проверки. Уже записанное в соединение сообщение отменить задним числом нельзя.

**Проверить текст** открывает дополнительный режим существующего **Тестирования**, сохраняя обычное сравнение моделей. Выберите **Вопрос зрителя** или **Готовый ответ бота**, введите точную строку и нажмите **Проверить локально** — API и ключ не нужны. Для ответа можно указать адресата; тогда строка должна уже содержать правильное обращение `@viewer `. **Проверить с AI** делает только один запрос оценки готового ответа, без генерации; при локальном запрете вызова нет. Для вопроса новый платный классификатор не добавляется. Используется применённая политика, её версия и модель показаны над формой; черновик надо явно применить в **Безопасности**. Диагностика не публикует текст, не добавляет его в память и не создаёт реальные события Twitch. Отмена, смена режима, изменение текста и закрытие отбрасывают поздний результат.

Последние решения используют совместимую дополнительную таблицу существующей SQLite-истории: только безопасные категории, этапы, модель, время оценки, версия и числа приложенных публичных пар/самостоятельных ответов с отметкой усечения, без исходного кандидата или сырого JSON проверяющего. Хранятся последние 200 событий, экран показывает 20. **Открыть историю** переносит в существующую страницу с фильтром выбранного сценария. Чтение SQLite выполняется в фоновом потоке; ошибка базы не меняет правила публикации. Результаты диагностики и сравнения моделей в этот список не записываются.

Для проверки через интерфейс выберите модель во вкладке **Тестирование** и сравните обычный игровой вопрос, просьбу раскрыть адрес и кандидат с личным обвинением. Проверьте статусы результата. Для самостоятельного режима начните с **Предпросмотра**, удалите сообщение-основание во время подготовки и проверьте отмену в **Активности**. Живые тесты моделей расходуют API-запросы.

Разработка ведётся в ветке `dev`. Автоматические проверки не требуют Twitch и платного API: `python -m unittest discover -s tests`. Проверки PySide6: `python tests/smoke_testing.py`, `python tests/smoke_privacy.py`, `python tests/smoke_local_context.py` и `python tests/smoke_history.py`; для запуска без экрана задайте `QT_QPA_PLATFORM=offscreen`.

## Сохранение и обновление

В разделе **История** доступны ответы на награды, самостоятельные реплики, предпросмотры и решения промолчать за все запуски. Выберите запись, чтобы увидеть запрос, ответ, модель и результат отправки. Контекст самостоятельной реплики и инструкции раскрываются по кнопке; для молчания контекст не сохраняется. Есть поиск, фильтры и переход к старым записям.

История сохраняется локально в `message-history.sqlite3` в папке с данными. Если бот самостоятельно ответил вам с `@логином`, продолжить разговор можно через награду: например, спросить «Почему ты так сказала?». В запрос добавляется последний успешно отправленный личный самостоятельный ответ за 30 минут с временем, получателем и краткими сообщениями-основаниями. Получатель сопоставляется по Twitch ID; при отсутствии сохранённого ID — по точному логину. Это работает и после перезапуска. Предпросмотры, отмены, ошибки и общие реплики не добавляются; ошибка чтения истории не мешает ответу. История вопросов через награды сохраняется без дублирования реплик.

В самостоятельном режиме бот отдельно определяет автора, исходного адресата (бот, владелец, зритель, группа или неизвестно), предмет сообщения и получателя своего ответа. Имена и aliases, Twitch reply и явные обращения помогают различить роли; разбор каждого сообщения и причина участия доступны в раскрываемом контексте истории. Бот не отвечает за стримера и может отклонить ошибочный план. Одно «ты» не означает обращение к боту: без достаточных признаков адресат остаётся неизвестным. По текстовому фрагменту без изображения, звука и полного чата стопроцентное понимание невозможно.

Ошибки выбора ситуации имеют отдельные безопасные коды: `autonomous_selection_api`, `_timeout`, `_truncated`, `_json`, `_schema`, `_roles` (последние суффиксы добавляются к `autonomous_selection`). Они различают API, ожидание, обрезку, JSON, схему и связность/роли; ошибки генерации используют префикс `autonomous_generation`. `autonomous_validation` означает проверку готовой реплики, `autonomous_send` — отправку. Исчерпание квоты (`quota_exhausted`), отмена и истечение срока (`ttl_expired`) сохраняют собственную причину, в том числе внутри проверки публикации.

`privacy_blocked` означает обнаруженные защищённые данные. `privacy_analysis_limit` означает незавершённую проверку из-за сложности, `privacy_check_error` — техническую ошибку проверки; такие входы тоже не передаются дальше, но не объявляются содержащими личные данные. Структурный обход JSON ограничен 16 уровнями, 16384 узлами и 200000 проверяемых символов; дополнительные преобразования имеют отдельный бюджет 64 попыток, двух слоёв и малых фрагментов. Обычные поля контекста не расходуют бюджет преобразований. Разные исходные строки JSON разбираются независимо от совпадения нормализованного текста; метки base64/hex сохраняют связь с соседними полями в своей структурной области. Проверенные ID из метаданных приложения учитываются отдельно; пользовательский JSON и тексты, включая промпты, заметки, историю и ответы AI, проверяются полностью.

В **Безопасности** история решений показывает запрос/ответ селектора и генератора, отдельные счётчики HTTP для выбора, генерации и оценки и попытку отправки в Twitch. Для старых записей новые счётчики показываются как «нет данных», а не как ноль. `ai_attempted` относится именно к отдельной AI-оценке публикации. Локальная ошибка до HTTP не расходует квоту; начавшаяся попытка HTTP, включая ошибку соединения, учитывается один раз. Снятие резерва допустимо только под блокировкой до HTTP, если срок истёк или произошла отмена во время сохранения счётчика. Сырые отклонённые ответы и найденные приватные значения не сохраняются. Тестирование и генератор промптов не читают реальную историю стрима и не записываются в неё. Статус «Отправлено» означает успешную передачу сообщения в соединение Twitch; ошибки и отмены отмечаются отдельно.

- **Сохранить** или `Ctrl+S` сохраняет подключение, общий промпт и профили. Для применения этих изменений к работающему боту остановите и запустите его снова.
- В самостоятельных репликах и локальном контексте используйте собственные кнопки **Применить**. Эти изменения доступны без перезапуска бота.
- **Папка с данными** открывает настройки, память и журнал. В готовой сборке они хранятся в `%APPDATA%\TwitchAIBot`, в исходниках — рядом с приложением.

При обновлении замените приложение; папку с данными сохраните. Заметки о канале и зрителях можно редактировать в `memory.json` по шаблону [memory.example.json](memory.example.json), предварительно остановив бота. Файлы настроек содержат ключи и токены — не публикуйте их.

## Если бот не отвечает

Посмотрите ошибку в **Активности**. Проверьте авторизацию обоих Twitch-аккаунтов, название награды и ввод текста. Для ошибок AI проверьте Base URL, ключ, баланс и доступность модели.

Возврат баллов при ошибке выполняется вручную в Twitch. Для диагностики передавайте текст ошибки без ключей и токенов.
