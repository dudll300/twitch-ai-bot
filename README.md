# ИИ-бот для Twitch

Зритель пишет `!бот Почему небо синее?`, бот отвечает в чат от собственного Twitch-аккаунта. Поддерживает DeepSeek и другие сервисы с OpenAI-совместимым `chat/completions`, в том числе `ai.starimg.ru`, если его текстовая модель поддерживает этот метод.

## Что понадобится

- Компьютер, который остаётся включённым во время стрима, и Python 3.10+.
- Отдельный Twitch-аккаунт для бота.
- Приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps) с типом **Public**. Нужен только **Client ID**; Client Secret в этот проект не вставляется.
- Ключ AI API, адрес API и ID текстовой модели.

## Запуск

1. Скачайте проект и откройте его папку. Скопируйте `.env.example` в `.env`.
2. Заполните `.env`: имя канала, логин бота, Twitch Client ID, данные AI API. Для DeepSeek адрес `https://api.deepseek.com`, модель `deepseek-flash`. Для `ai.starimg.ru` скопируйте Base URL и ID доступной текстовой модели из кабинета. К Base URL бот добавляет `/chat/completions`.
3. Запустите в папке проекта `py bot.py` (или `python bot.py`). При первом запуске откроется Twitch; войдите **под аккаунтом бота** и подтвердите права `chat:read` и `chat:edit`.
4. Дождитесь строки `Подключаюсь к чату ...`. Отправьте в чат `!бот Привет!`.

Токены Twitch сохраняются рядом с программой в `.twitch_token.json` и обновляются автоматически. Twitch может попросить повторить вход, если токен отозван или срок его действия истёк. Остановить бота можно сочетанием Ctrl+C.

Файлы `.env` и `.twitch_token.json` содержат секреты и исключены из Git. Не публикуйте их и не отправляйте в переписке. Если бот работает на компьютере знакомой, она должна сама войти в Twitch под аккаунтом бота; ключ AI API можно настроить локально на этом компьютере.

## Ограничения и настройки

- Один запрос на весь чат раз в 10 секунд и один запрос от зрителя раз в 60 секунд; очередь до трёх вопросов.
- Вопрос ограничен 400 символами, ответ — одной строкой до 350 символов. История разговора не хранится.
- При разрыве соединения бот подключается снова. Если компьютер выключен, бот не работает.
- Каждый вопрос отправляется выбранному AI-провайдеру и расходует его оплачиваемые API-запросы.
