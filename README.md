# Чунда — ИИ-бот для Twitch

Бот отвечает на вопросы из награды Twitch за баллы канала «Иишка». Зритель вводит вопрос при получении награды, а Чунда отвечает от отдельного Twitch-аккаунта. Обычные сообщения чата и команда `!бот` не запускают ответ. Основная модель по умолчанию — `deepseek-v4.1-flash`; при временных сбоях бот пробует остальные модели по очереди.

Когда награду получает владелица канала, Чунда узнаёт её по Twitch-логину канала из настроек и отвечает особенно ласково, обращаясь «госпожа». Для остальных зрителей сохраняется обычный характер Чунды.

## Что понадобится

- Компьютер с Windows. Для запуска из исходников нужен Python 3.10 или новее; готовой сборке Python не нужен. Компьютер должен быть включён, пока бот работает на стриме.
- Логин Twitch-канала и отдельный Twitch-аккаунт для бота.
- **Client ID** приложения типа **Public** из [Twitch Developer Console](https://dev.twitch.tv/console/apps). Client Secret не нужен.
- API-ключ `ai.starimg.ru` с доступом к основной и запасным моделям.
- Награда канала **«Иишка»** стоимостью 200 баллов. В настройках награды включите **обязательный ввод текста**. Создать награду можно в панели управления Twitch.

## Запуск приложения на Windows

Готовая Windows-сборка создаётся автоматически в [GitHub Actions](https://github.com/dudll300/twitch-ai-bot/actions/workflows/windows-gui.yml) для ветки `dev`. Откройте последний успешный запуск, скачайте артефакт **Chunda-Windows**, извлеките из него `Chunda.exe` и запустите его. Это один файл; Python устанавливать не нужно.

Для запуска из исходников скачайте ветку `dev`, распакуйте её и откройте `launch_gui.bat`. При первом запуске скрипт создаст локальное окружение и установит зависимости. В следующие разы он сразу откроет приложение.

Чтобы собрать `.exe` самостоятельно, откройте PowerShell **в корне распакованной ветки `dev`**, где лежат `app.py` и `requirements.txt`, и выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt pyinstaller==6.22.3
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name Chunda --add-data "memory.example.json;." app.py
```

Готовый файл появится в `dist\Chunda.exe`.

1. Заполните логин канала, логин отдельного аккаунта бота, Twitch Client ID и API-ключ. Base URL по умолчанию — `https://ai.starimg.ru/v1`.
2. Выберите основную модель DeepSeek из списка.
3. При желании измените системный промпт Чунды и нажмите **Запустить бота**. Настройки сохранятся автоматически.
4. При первом запуске Twitch попросит войти дважды: сначала **под аккаунтом бота** для доступа к чату, затем **под аккаунтом стримерши** для чтения награды. Код подтверждения и нужный аккаунт появятся на вкладке **Работа**.
5. Получите награду «Иишка», впишите в неё вопрос и проверьте ответ в чате.

Кнопка **Остановить** завершает работу бота. Изменения модели и промпта применяются при следующем запуске. Настройки сохраняются в `.env`, промпт — в `prompt.txt`, токен бота — в `.twitch_token.json`, токен стримерши — в `.twitch_broadcaster_token.json`. Эти файлы и `memory.json` исключены из Git. В готовой сборке они находятся в `%APPDATA%\ChundaBot`; кнопку для открытия папки найдёте на вкладке **Работа**.

## Запуск без GUI

На Windows запустите `start.bat`; на macOS или Linux — `python3 start.py`. Консольный мастер попросит заполнить настройки при первом запуске. Позже можно повторить настройку через `start.bat --setup` или `python3 start.py --setup`. Модель и промпт, сохранённые через GUI, работают и при консольном запуске.

## Память о стримере и зрителях

При первом запуске бот создаёт локальный `memory.json` из [memory.example.json](memory.example.json). Остановите бота, отредактируйте `memory.json` и запустите его снова. При последующих запусках файл не перезаписывается.

- `streamer.facts` — короткие факты о стримере.
- `streamer.jokes` — шутки и особенности канала.
- `viewers` — карточки зрителей, которых бот должен узнавать.

В шаблоне есть объект `_example_viewer_copy_into_viewers`. Это образец: бот его игнорирует. Скопируйте объект в массив `viewers` и замените значения:

```json
{
  "login": "pelmen",
  "user_id": "",
  "facts": ["Любит хорроры"],
  "jokes": ["Можно дружески подколоть про скримеры"],
  "avoid": ["Не шутить про личную жизнь"]
}
```

`login` — Twitch-логин маленькими латинскими буквами, без `@`. `user_id` можно оставить пустым: тогда карточка ищется по логину. Если указать числовой Twitch ID, бот узнает зрителя и после смены логина. В `facts` записывайте только то, что допустимо повторить в эфире; `jokes` задаёт темы для шуток, а `avoid` — темы, которых следует избегать.

Для каждого зрителя бот держит в оперативной памяти последние 10 успешно отправленных ответов Чунды вместе с вопросами (20 сообщений). Это позволяет продолжать диалог через следующие получения награды. После перезапуска история очищается; она не записывается в `memory.json`. К AI-сервису передаются заметки о стримере, карточка только текущего зрителя и его история. `memory.json` исключён из Git: не добавляйте заполненный файл в публичный репозиторий.

## Если бот не запускается

- Убедитесь, что установлен Python 3.10+ и он доступен из командной строки. На Windows после установки Python может понадобиться открыть `start.bat` заново.
- Проверьте логины, Twitch Client ID и Base URL командой запуска с `--setup`.
- Убедитесь, что при первой авторизации выбран аккаунт бота, а при второй — аккаунт стримерши.
- Проверьте название награды «Иишка», обязательный ввод текста и доступность награды на канале.
- Проверьте, что API-ключ действителен и у него есть доступ к выбранной модели. Запасные модели указаны ниже.
- При `HTTP 400` откройте вкладку **Работа**: бот покажет короткую причину от AI API и попробует другие модели DeepSeek.
- Если ошибка указывает на `memory.json`, проверьте синтаксис JSON и структуру полей по шаблону.

Для помощи с ошибкой достаточно передать её текст. Не передавайте содержимое `.env`, файлов `.twitch*token.json` или заполненного `memory.json`.

## Дополнительно

- Вопрос из награды: максимум 400 символов; ответ: максимум 300 символов.
- Бот обрабатывает ответы по одному; в очереди может ждать до 10 вопросов. Если она заполнена, бот сообщит зрителю о проблеме, а стримерше потребуется вручную проверить возврат баллов. То же касается сбоя AI после получения награды: награда, созданная через Twitch, автоматически не возвращается.
- Список моделей: `deepseek-v4.1-flash`, `deepseek-v4.1-pro`, `deepseek-v4-flash`. Если модель не отвечает, возвращает пустой ответ или временную ошибку, бот пробует следующую по списку, пропуская выбранную основную. После трёх подряд сбоев основной модели бот пропускает её 5 минут, затем проверяет снова. Таймаут каждой попытки — 20 секунд; если недоступны все модели, очередь вопросов будет расти. Если в старых настройках указана другая модель, бот переключится на `deepseek-v4.1-flash`.
- Каждый запрос к модели может расходовать баланс API.
- Проверка кода: `python -m unittest discover -s tests -v` (на macOS/Linux используйте `python3`).

Документация: [Twitch EventSub](https://dev.twitch.tv/docs/eventsub/handling-websocket-events), [награды канала](https://dev.twitch.tv/docs/api/reference#get-custom-reward), [Twitch OAuth](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow).
