# ИИ-бот для Twitch

Зритель пишет `!бот Почему небо синее?`, бот отвечает в чат от собственного Twitch-аккаунта. Проект подготовлен для `ai.starimg.ru`: нужны его Base URL, ключ и ID текстовой модели с поддержкой OpenAI-совместимого `chat/completions`. Также можно подключить другой совместимый сервис.

## Что понадобится

- Компьютер, который остаётся включённым во время стрима, и Python 3.10+.
- Отдельный Twitch-аккаунт для бота.
- Приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps) с типом **Public**. Нужен только **Client ID**; Client Secret в этот проект не вставляется.
- Ключ AI API, адрес API и ID текстовой модели.

## Запуск

1. Скачайте проект. На Windows дважды щёлкните `start.bat`; на macOS/Linux запустите `python3 start.py` в папке проекта.
2. При первом запуске скрипт спросит логин канала, логин отдельного аккаунта бота, Twitch Client ID, Base URL, ключ и ID модели AI. Для `ai.starimg.ru` возьмите Base URL и ID текстовой модели из личного кабинета. Модель должна поддерживать `chat/completions`. Если вставить полный адрес с `/chat/completions`, скрипт сам уберёт этот суффикс.
3. В открывшемся окне Twitch войдите **под аккаунтом бота** и подтвердите права `chat:read` и `chat:edit`.
4. Дождитесь строки `Подключаюсь к чату ...`. Отправьте в чат `!бот Привет!`.

Настройки сохраняются в локальном `.env`, а при следующих запусках скрипт сразу включает бота. Чтобы изменить данные, запустите `start.bat --setup` на Windows или `python3 start.py --setup` на macOS/Linux. Поле ключа AI скрыто при вводе; при повторной настройке нажмите Enter, чтобы оставить прежний ключ.

Токены Twitch сохраняются рядом с программой в `.twitch_token.json` и обновляются автоматически. Twitch может попросить повторить вход, если токен отозван или срок его действия истёк. Остановить бота можно сочетанием Ctrl+C.

Файлы `.env` и `.twitch_token.json` содержат секреты и исключены из Git. Не публикуйте их и не отправляйте в переписке. Если бот работает на компьютере знакомой, она должна сама запустить настройку и войти в Twitch под аккаунтом бота.

Если вместо `ai.starimg.ru` решите использовать DeepSeek, укажите `AI_BASE_URL=https://api.deepseek.com` и ID доступной модели в `AI_MODEL`.

## Ограничения и настройки

- Один запрос на весь чат раз в 10 секунд и один запрос от зрителя раз в 60 секунд; очередь до трёх вопросов.
- Вопрос ограничен 400 символами, ответ — одной строкой до 350 символов. История разговора не хранится.
- При разрыве соединения бот подключается снова. Если компьютер выключен, бот не работает.
- Каждый вопрос отправляется выбранному AI-провайдеру и расходует его оплачиваемые API-запросы.
