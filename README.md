# Twitch AI Bot

Бот отвечает в Twitch-чате на вопросы через награду за баллы канала. Дополнительно он может участвовать в разговоре самостоятельно. Манеру общения задаёте вы: через общий промпт, личные инструкции зрителей и контекст канала.

## Что нужно

- Windows для готового приложения и доступ к интернету.
- Twitch-канал с наградами за баллы и отдельный Twitch-аккаунт бота.
- Client ID приложения типа **Public** из [Twitch Developer Console](https://dev.twitch.tv/console/apps). Client Secret не нужен.
- AI-сервис с совместимым API Chat Completions: Base URL, API-ключ и доступная модель.

**Для тестирования ответов нужны только данные AI-сервиса — подключать Twitch не требуется.** AI-запросы, включая генерацию промптов и предпросмотр, могут расходовать баланс провайдера.

## Запуск

1. Откройте [сборки Windows](https://github.com/dudll300/twitch-ai-bot/actions/workflows/windows-gui.yml) и выберите успешный запуск ветки `dev`.
2. Скачайте артефакт **TwitchAIBot-Windows** и распакуйте архив. Для скачивания может понадобиться вход в GitHub.
3. Запустите `TwitchAIBot.exe`. Python для готовой сборки не нужен.

Для запуска из исходников установите Python 3.10+ (рекомендуется 3.12), скачайте ветку `dev` и откройте `launch_gui.bat`. Скрипт подготовит окружение и установит зависимости. Для запуска без интерфейса используйте `start.bat`.

## Первое подключение

1. Создайте в Twitch награду за баллы канала и включите **обязательный ввод текста**.
2. В разделе **Подключение** укажите канал, аккаунт бота, Client ID и точное название награды.
3. Заполните Base URL, API-ключ и основную модель. ID модели можно ввести вручную или выбрать из списка. **Загрузить модели провайдера** получает каталог по вашему запросу. Запасные модели необязательны.
4. В **Поведении** задайте общий промпт: как бот должен отвечать и общаться. Изначально он пуст.
5. Нажмите **Запустить бота** и пройдите авторизацию аккаунта бота и владельца канала. Ссылки и коды появятся в **Активности**.
6. Дождитесь подключения и проверьте ответ через награду.

Приложение должно оставаться запущенным. Кнопка **Остановить бота** завершает его работу.

## Настройка ответов

**Поведение.** Напишите промпт вручную, выберите пресет или опишите пожелания AI-генератору. Настройте темперамент и стиль. Выберите доступную модель и нажмите **Сгенерировать промпт**. Проверьте вариант и нажмите **Применить к общему промпту**. Для доработки существующего текста используйте **Улучшить текущий промпт**. Пресеты работают без AI-запросов. Обычный ответ ограничен 400 символами.

**Зрители.** Добавьте профиль, укажите логин или Twitch ID и личную инструкцию. В поле **Другие имена / ники** можно добавить варианты имени, чтобы бот узнавал зрителя в чужих вопросах и чате. Отключённая личная инструкция не применяется.

**Локальный контекст.** Добавьте карточки выражений и отсылок канала: название, другие варианты написания, значение и условия использования. Включите систему и нажмите **Применить**. Частоту отсылок можно настроить отдельно.

## Проверка без Twitch

В **Тестировании** введите вопрос, выберите отправителя и одну или несколько моделей, затем нажмите **Получить ответы**. Можно сравнить текст, время ожидания и ошибки разных моделей.

Тест учитывает текущий промпт и изменения профилей, даже до сохранения. История реальных разговоров не используется. Тестовые вопросы и ответы не публикуются в чате и не сохраняются в память бота.

Кнопки **Проверить ответ** в **Поведении** и **Зрителях** открывают тест с выбранным контекстом. Для нового промпта генератора используйте **Проверить этот вариант**.

## Самостоятельные реплики

1. Подключите бота к чату и откройте **Самостоятельные реплики**.
2. Выберите характер участия, настройте паузу и максимум реплик за час. Дополнительные параметры находятся в **Расширенных настройках**.
3. При необходимости заполните отдельные инструкции участия и нажмите **Применить**.
4. Включите режим и сначала проверьте его в **Предпросмотре**: предложенные сообщения будут видны только в журнале.
5. Когда результат устраивает, переключитесь на **Публикацию**, чтобы бот отправлял реплики в чат.

Бот реагирует на свежие обсуждения и может промолчать. Самостоятельный режим по умолчанию выключен. **Сбросить настройки** возвращает начальные параметры и выключает режим.

## Сохранение и обновление

- **Сохранить** или `Ctrl+S` сохраняет подключение, общий промпт и профили. Для применения этих изменений к работающему боту остановите и запустите его снова.
- В самостоятельных репликах и локальном контексте используйте собственные кнопки **Применить**. Эти изменения доступны без перезапуска бота.
- **Папка с данными** открывает настройки, память и журнал. В готовой сборке они хранятся в `%APPDATA%\TwitchAIBot`, в исходниках — рядом с приложением.

При обновлении замените приложение; папку с данными сохраните. Заметки о канале и зрителях можно редактировать в `memory.json` по шаблону [memory.example.json](memory.example.json), предварительно остановив бота. Файлы настроек содержат ключи и токены — не публикуйте их.

## Если бот не отвечает

Посмотрите ошибку в **Активности**. Проверьте авторизацию обоих Twitch-аккаунтов, название награды и ввод текста. Для ошибок AI проверьте Base URL, ключ, баланс и доступность модели.

Возврат баллов при ошибке выполняется вручную в Twitch. Для диагностики передавайте текст ошибки без ключей и токенов.
