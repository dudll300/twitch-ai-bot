# Чунда — ИИ-бот для Twitch-чата

Зритель пишет `!бот Вопрос`, Чунда отвечает от отдельного Twitch-аккаунта. Для ответов используется **`deepseek-v4.1-flash` через `https://ai.starimg.ru/v1`**. Чунда язвит, шутит и часто ругается матом; её системный промпт находится в `bot.py`.

## Что подготовить заказчице

1. Twitch-логин канала, где будет работать Чунда.
2. Отдельный Twitch-аккаунт для бота. В его аккаунт нужно будет войти при первом запуске.
3. Приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps) с типом **Public**. Из него понадобится **Client ID**, не Client Secret.
4. API-ключ ai.starimg.ru. Андрей передаст его отдельно. **Не отправляйте ключ в чат с GPT и не добавляйте в GitHub.** Если в кабинете указан другой Base URL, используйте адрес из кабинета.
5. Компьютер с Python 3.10 или новее, который остаётся включённым во время стрима.

## Первый запуск

1. Скачайте репозиторий: на GitHub нажмите **Code → Download ZIP** и распакуйте архив.
2. На Windows дважды щёлкните `start.bat`. На macOS/Linux запустите `python3 start.py` из папки проекта.
3. Скрипт спросит логины канала и бота, Twitch Client ID, Base URL и API-ключ. Для Base URL можно нажать Enter и оставить `https://ai.starimg.ru/v1`. Модель уже выбрана — `deepseek-v4.1-flash`.
4. В открывшемся окне Twitch войдите **под отдельным аккаунтом бота** и подтвердите доступ к чату.
5. После строки «Подключаюсь к чату» отправьте в чат `!бот Привет, Чунда!`.

При следующем запуске настройки считываются из локального `.env`. Для изменения настроек запустите `start.bat --setup` или `python3 start.py --setup`. OAuth-токены Twitch сохраняются в `.twitch_token.json`. Оба файла исключены из Git. При проблемах с запуском передайте помощнику текст ошибки, но **не содержимое этих файлов**.

## Память о Софи и зрителях

Перед запуском отредактируйте [memory.json](memory.json). В `streamer.facts` добавьте короткие публичные факты о Софи, в `streamer.jokes` — локальные шутки канала. В `viewers` добавляйте карточки только тех людей, которых Чунда должна узнавать. Полную историю чата бот не сохраняет.

В файле уже есть `_example_viewer_copy_into_viewers`. Это **пример**, бот его игнорирует. Скопируйте объект из него в массив `viewers`, замените примерные значения и при желании удалите поле с примером. Карточка выглядит так:

```json
{
  "login": "pelmen",
  "user_id": "",
  "facts": ["Любит хорроры", "Боится скримеров"],
  "jokes": ["Можно дружески подкалывать про скримеры"],
  "avoid": ["Не шутить про личную жизнь"]
}
```

- `login` — Twitch-логин **маленькими латинскими буквами**, без `@`; обязателен.
- `user_id` — числовой Twitch ID. Его можно оставить пустым: тогда карточка ищется по логину. Если ID указан, Чунда узнает человека по ID даже после смены ника. Twitch передаёт `user-id` в тегах сообщения.
- `facts` — только факты, которые можно повторять вслух на стриме.
- `jokes` — разрешённые направления для подколов, не утверждения о человеке.
- `avoid` — темы, которых Чунда должна избегать с этим зрителем.

Если карточки нет, Чунда отвечает без персональной памяти. При каждом вопросе AI-сервису передаются только факты о Софи и карточка автора вопроса. Не записывайте в `memory.json` адреса, настоящие имена, контакты и другие личные сведения: файл предполагается хранить в репозитории, а заполненные заметки отправляются AI-сервису при ответе. После изменения файла перезапустите бота. Ошибку в структуре файла бот покажет при запуске вместо молчаливого игнорирования памяти.

## Как попросить GPT помочь с настройкой

Отправьте ссылку на репозиторий и примерно такой запрос:

> Помоги мне по README запустить Twitch-бота Чунду на моём компьютере. Спрашивай по одному шагу и объясняй простыми словами. Не проси присылать тебе API-ключ, `.env` или `.twitch_token.json`: я введу секреты только в локальное окно настройки. Если появится ошибка, помоги по её тексту.

GPT сможет прочитать репозиторий по ссылке, только если у него есть доступ к нему. Если репозиторий приватный и доступа нет, нужно отдельно предоставить GPT файлы `README.md`, `start.py`, `bot.py`, `memory.py` и `memory.json` без локальных секретов.

## Технические детали

- Команда: `!бот вопрос`; максимум 400 символов вопроса и 300 символов ответа.
- Ограничение частоты: один запрос на весь чат раз в 10 секунд, один запрос от зрителя раз в 60 секунд, очередь до трёх вопросов.
- Бот использует Twitch IRC с тегами сообщений и OpenAI-совместимый `chat/completions` AI STAR.
- Память загружается при запуске. Она редактируется вручную и не пополняется из сообщений чата.
- Каждый вызов модели может расходовать оплачиваемый баланс API.
- Проверка кода: `python -m unittest discover -s tests -v`.

Документация: [Twitch IRC](https://dev.twitch.tv/docs/chat/irc/), [Twitch OAuth](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow).
